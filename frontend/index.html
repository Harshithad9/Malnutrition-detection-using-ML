    About NutriScan

    Advanced Malnutrition Detection System

    NutriScan is an intelligent screening tool designed to detect early signs of malnutrition in children through advanced image analysis and anthropometric assessment.

    Key Features

    • AI-powered image analysis for initial screening
    • Comprehensive nutritional assessment calculations
    • Professional report generation
    • Evidence-based recommendations
    • Multi-metric evaluation (BMI, Wasting, Stunting, MUAC)

    How It Works

    1. Upload a clear frontal image of the child
    2. System performs initial visual assessment
    3. Enter anthropometric measurements (height, weight, age)
    4. Receive comprehensive analysis and recommendations
    5. Download professional PDF report
